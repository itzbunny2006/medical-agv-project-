📌 1. Project Overview

The Medical Automated Guided Vehicle (AGV) is a smart robotic vehicle designed to transport medicines, medical equipment, and essential healthcare supplies inside hospitals.

This project combines an Autonomous Guided Vehicle with a 6-DOF robotic arm to support medicine handling and delivery. The ESP32 microcontroller acts as the main controller, managing vehicle movement, sensor operations, and robotic arm control.

The system includes a medicine storage box, camera, TFT touchscreen display, ultrasonic sensor, IR sensors, emergency lights, and a four-wheel drive platform.

The main aim of this project is to reduce the manual workload of healthcare staff, save time, improve transportation efficiency, and support smart hospital automation.

🎯 2. Project Objectives

- To develop an ESP32-based Medical AGV.
- To automate medicine transportation inside hospitals.
- To integrate a 6-DOF robotic arm for medicine handling.
- To control the robotic arm using servo motors.
- To control vehicle movement using a motor driver.
- To detect obstacles using an ultrasonic sensor.
- To implement path detection using IR sensors.
- To provide visual monitoring through a camera.
- To improve hospital transportation efficiency and safety.

🧠 4. ESP32 Microcontroller

The ESP32 is the main controller of the Medical AGV. It processes sensor information and controls the connected hardware components.

Functions of ESP32

- Controls DC motors through the motor driver.
- Controls the 6-DOF robotic arm using servo motors.
- Receives signals from IR sensors.
- Processes ultrasonic sensor measurements.
- Supports TFT touchscreen interfacing.
- Coordinates the connected system modules.

🤖 5. 6-DOF Robotic Arm

The Medical AGV includes a 6-DOF robotic arm operated using servo motors and the ESP32 microcontroller.

Working Principle

1. The ESP32 generates control signals for the servo motors.
2. Each servo motor controls a joint of the robotic arm.
3. The six degrees of freedom provide different arm movements.
4. The robotic arm can be programmed to pick and handle medicines.
5. It supports medicine handling and delivery operations.

Controller: ESP32
Actuators: Servo Motors
Application: Medicine Handling

🚗 6. AGV Motor Control System

The vehicle movement is controlled by the ESP32 through a motor driver.

Working Principle

1. IR sensors detect the predefined path.
2. The ESP32 processes the sensor signals.
3. The ESP32 sends control signals to the motor driver.
4. The motor driver controls the DC gear motors.
5. The vehicle moves according to the programmed instructions.
6. The ultrasonic sensor detects obstacles in front of the vehicle.

Controller: ESP32
Motor Controller: Motor Driver
Actuators: DC Gear Motors

🔄 7. Overall Working Principle

1. The Medical AGV is switched ON.
